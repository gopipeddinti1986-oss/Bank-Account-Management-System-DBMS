# 🏦 Bank Account Management System

A Database Management System (DBMS) project designed to manage and organize banking information such as branches, customers, employees, accounts, loans, and transactions.

---

## 📌 Project Overview

The **Bank Account Management System** provides a structured relational database for managing banking operations and maintaining relationships between different banking entities.

The project demonstrates database design, table creation, data manipulation, constraints, and SQL queries.

---

## 🎯 Objectives

- Design a structured relational database for a banking system.
- Create tables using appropriate primary keys and foreign keys.
- Apply database constraints to maintain data integrity.
- Insert and manage sample banking data.
- Perform CRUD operations.
- Perform SQL JOIN operations.
- Use aggregate functions for data analysis.
- Design and represent the database using an ER diagram and relational schema.

---

## 🗄️ Database Entities

The database consists of the following major entities:

- **Branch**
- **Customer**
- **Employee**
- **Account**
- **Loan**
- **Transaction**

These entities are related using primary keys and foreign keys to maintain data consistency and integrity.
